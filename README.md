# rosalind_1

A practice program: my first bit of code committed and pushed end to end while learning the everyday tools (Python, git, GitHub). Hello-world energy, not a real project.

## What it does

Counts the four DNA bases (A, C, G, T) in a hardcoded DNA sequence and prints each count. This is [Rosalind problem 1, "Counting DNA Nucleotides."](https://rosalind.info/problems/dna/)

## Run it

```bash
python rosalind_1.py
```

Output:

```
A=20
C=12
G=17
T=21
```

That matches the known answer for the Rosalind sample sequence, so the logic checks out.
